ANTES DE EMPEZAR

Buenas preguntas.

¿Necesito conocimientos previos?

Excel e IA aplicada empiezan desde cero. Para Power BI necesitas manejar Excel a nivel básico.

¿Qué equipo necesito?

Una computadora con conexión a internet. Para Excel necesitas Microsoft Excel; para Power BI, Windows y Power BI Desktop. IA aplicada se trabaja desde el navegador.

¿Cómo me inscribo?

Este catálogo es una demostración académica. Puedes consultar los programas con el asistente; no se procesan matrículas ni pagos.
